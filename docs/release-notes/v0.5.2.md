# Enginewright v0.5.2

Early preview. Supported: **Unreal Engine 5.8, Windows (Win64)**. Other engine versions, Mac and Linux are not tested yet.

This release closes the 0.5 series (0.5.0, 0.5.1 and 0.5.2 are released together). Every tool was used on a real game project before the tag.

## Install or update

1. Close the editor. Delete an older `Plugins/Enginewright` folder, then unzip into your project's `Plugins/` folder, so you get `<YourProject>/Plugins/Enginewright/Enginewright.uplugin`.
2. Optional, only if the project uses MVVM (Epic's UMG Viewmodel plugin): unzip `EnginewrightMVVM-0.5.2-UE5.8-Win64.zip` into `Plugins/` too, then enable `EnginewrightMVVM` in Edit > Plugins and restart. Skip it otherwise: Enginewright works without it.
3. Open the project. The status bar (bottom right) shows `Enginewright :3100` with a green dot.
4. Click it to open the Enginewright panel and copy the config for your client (Claude Code, Codex, Cursor, VS Code, Hermes). The same files are in `<YourProject>/Saved/Enginewright/clients/`.
5. Ask your agent to call `doctor`.

Your token and port stay the same after an update. If a local web tool of yours calls the server from a browser page, add its origin to the new `AllowedOrigins` setting (see Security).

## Highlights

- Reliability round: all 132 tools were called on a real game project, 996 checked calls. Two editor crashes and 12 other problems were found and fixed, each with a test. See [RELIABILITY_0.5.md](../RELIABILITY_0.5.md).
- `text_overflow_audit` finds UI text that does not fit its slot, per language and screen size.
- `datatable_import` brings a CSV or JSON file into a DataTable with a diff and `dryRun`; `level_audit` lists hidden, idle and placeholder actors.
- The server refuses requests from web pages of other sites (`Origin` check).
- [Use it together with Epic's MCP server](../WITH_EPIC_MCP.md): both in one editor, one agent.

## New

- `text_overflow_audit`: for each visible TextBlock of a Widget Blueprint or UserWidget class (or the open UI during Play In Editor), the width the text wants against the width its slot gives it, per language. Game text is measured translated, also in the editor.
- `datatable_import`: CSV or JSON file into a DataTable (upsert) with a strict field check, a diff of added / changed / removed rows, `dryRun`, and a read-back after the write.
- `level_audit`: hidden actors, visible static-mesh actors with no gameplay component, and meshes that match placeholder / kit name patterns, on the open level or a saved map.
- `AllowedOrigins` setting and [docs/WITH_EPIC_MCP.md](../WITH_EPIC_MCP.md).

## Security

- The HTTP server refuses requests whose `Origin` header names another web site (403, before the token check), so a web page open in a browser cannot reach the editor. Requests without `Origin` (MCP clients, scripts) and from `localhost`, `127.0.0.1` or `[::1]` pass.

## Fixed

- Editor crash: `widget_get` without `properties` on a panel widget (the property reader followed the slot back to the widget forever).
- Editor crash: `widget_set` stored an enum number outside the enum and the next render asserted. Out-of-range numbers are now refused with the valid names, for every property write.
- Number arguments are checked against the schema range for every tool (negative sizes and durations, `top: 0`, holds above the limit).
- `FOLDER_NOT_FOUND` from `asset_search_text`, `id_audit` and `ui_input_audit`; `MAP_NOT_FOUND` from `mrq_render`; a broken `id_audit` regex is refused.
- `log_read` `minVerbosity` no longer returns empty lines; `blueprint_info` reads variable defaults after a compile.
- From the 0.5.0 game run: `stringtable_compare` (a format argument used twice, CRLF sources), `asset_rename` `referencersUpdated`, `datatable_import` warnings, full paths in results, `text_overflow_audit` in the editor.

## Changed

- `asset_find` warns about a folder that does not exist; `asset_import` and `blueprint_create` warn about non-ASCII asset names.
- `game_run` `keepRuns` (default 20) removes the oldest run folders; `pie_start` waits longer for several players; `actor_preview` frames a character with a camera boom tighter.
